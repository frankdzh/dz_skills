# 多智能体会话日志模糊与语义检索实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个零常驻后台守护、零外部 API 依赖的跨 20+ 款编程智能体会话日志模糊与语义检索技能，支持任意灵活时间窗口与毫秒级高密度看板输出。

**Architecture:** 采用三层渐进式检索流水线：第一层灵活时空窗口过滤初筛，第二层 SQLite `:memory:` FTS5 倒排索引做全域会话与工具日志快速召回，第三层基于本地轻量向量/内置词元加权算法进行混合语义重排与命中片段高亮提纯。

**Tech Stack:** Python 3 (标准库 sqlite3 FTS5, json, glob, datetime, re, urllib) + 本地轻量计算 (sentence_transformers, numpy, 降级纯数学算法)。

**Spec:** [多智能体会话日志模糊与语义检索技能设计与实现规范.md](./多智能体会话日志模糊与语义检索技能设计与实现规范.md)

## Global Constraints

- 零常驻后台服务：绝不启动常驻 daemon、端口监听或后台守护进程。
- 零外部付费 API：离线安全，不向外网发送 Token 或 API 请求。
- 优雅降级防护：无网络或本地向量模型未就绪时，纯靠内置算法 100% 可用且不报错。
- 文档与命名契约：所有开发规范与计划文档一律采用中文命名；技能目录规范命名为 `transcript-search`。

## Review Focus

- 输入非法时间格式（如 `--since invalid`）时，程序应优雅回退至默认 7 天并给出警示，不可崩溃抛异常。
- 极端大日志文件（>20MB transcript.jsonl）深搜时，逐行流式读取且设 1.5 秒超时熔断，不可阻塞整机。
- 搜索词包含特殊正则符号（如 `[`, `*`, `?`, `\`, `"`）时，FTS5 与模糊匹配需正确转义，不可语法报错。
- 本地日志包含敏感凭据（API_KEY, PRIVATE KEY, Authorization）时，输出命中切片必须自动脱敏。
- 零命中时必须给出友好排查指引与时间窗口扩大建议，不可输出空白看板。
